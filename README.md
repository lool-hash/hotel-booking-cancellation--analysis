# 🏨 Hotel Booking Cancellation Analysis with PCA & Machine Learning

## 📌 Project Overview
This project focuses on analyzing hotel booking data to understand the main factors affecting booking cancellations.  
It applies data preprocessing, exploratory analysis, dimensionality reduction using PCA, and machine learning techniques to extract meaningful insights.

## 📊 Objectives
- Analyze customer booking behavior
- Identify key factors influencing cancellations
- Reduce data dimensionality using PCA
- Apply clustering and machine learning models
- Improve decision-making for hotel management

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📁 Dataset
Hotel booking dataset containing customer information, booking details, and cancellation status.

Features include:
- Lead time
- Country
- Agent & Company
- Deposit type
- Reservation status
- Arrival date
- Market segment

## 🔍 Methodology
1. Data Cleaning & Preprocessing  
   - Handling missing values
   - Feature encoding
   - Normalization and scaling

2. Exploratory Data Analysis (EDA)  
   - Statistical analysis
   - Data visualization
   - Trend analysis

3. Dimensionality Reduction  
   - Principal Component Analysis (PCA)

4. Machine Learning & Clustering  
   - Unsupervised clustering
   - Pattern discovery
   - Customer segmentation

## 📈 Key Findings
- Higher cancellation rates are associated with longer lead times
- Online bookings show higher cancellation probability
- Seasonal patterns affect booking behavior
- PCA improved model efficiency and visualization
