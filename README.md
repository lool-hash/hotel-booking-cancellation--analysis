# Hotel Booking Analysis with Principal Component Analysis (PCA)

## 📌 Project Overview
This project explores hotel booking data using **Principal Component Analysis (PCA)** to reduce data dimensionality while preserving important information. The project includes data preprocessing, exploratory data analysis (EDA), feature scaling, PCA implementation, and visualization of the transformed data.

## 🎯 Objectives
- Clean and preprocess hotel booking data.
- Perform exploratory data analysis (EDA).
- Standardize numerical features.
- Apply Principal Component Analysis (PCA).
- Visualize the principal components.
- Analyze the variance explained by each component.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📂 Dataset
The dataset contains hotel booking information such as:
- Hotel Type
- Lead Time
- Arrival Date
- Stays Duration
- Adults & Children
- Meal Type
- Market Segment
- Booking Status
- Customer Information
- Reservation Details

## 📊 Project Workflow
1. Import required libraries.
2. Load the dataset.

4. Exploratory Data Analysis (EDA).
5. Feature scaling using StandardScaler.
6. Apply PCA.
7. Visualize principal components.
8. Interpret PCA results.

## 📈 Visualizations
The project includes:
- Correlation Heatmap
- Feature Distribution
- PCA Scatter Plot
- Explained Variance Ratio
- Cumulative Explained Variance

## 🔍 Key Insights
- PCA successfully reduced the number of features while retaining most of the dataset's information.
- The first principal components captured the majority of the variance.
- Feature reduction improves computational efficiency and simplifies data visualization.
- PCA can be used as a preprocessing step before machine learning models.
